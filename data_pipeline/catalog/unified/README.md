# Unified data catalog

This directory is generated by `data_pipeline/catalog/build_unified_catalog.py`.

- `unified_data_catalog.parquet` and `.csv` describe physical queryable assets.
- `unified_metric_catalog.parquet` contains EVDS metadata plus locally available
  EVDS, BDDK and TBB metrics.
- `queryable_metric_catalog.csv` contains only metrics with local observations.
- `validation.json` records completeness, duplicate-key checks and known source
  gaps.

Metadata-only EVDS entries are explicitly marked with
`observation_available=false`. They must not be treated as downloaded values.

The BDDK weekly collection is complete: all 2,574 requested source pages were
downloaded and validated. The catalog builder still derives the status from the
download manifest, so a future partial refresh remains visible as `in_progress`
instead of being presented as complete.
